# M4 brief D (observer, dark content, reference sims, validation) — key points kept for synthesis
Sources read in full by the agent: 15-05, 06-10, 02-06, 07-09, 07-11, 16-01, 16-02, 16-03.

God tools (15-05 §4.2: only physical changes or perceptible events; never set religion, declare war, pass laws, pick actions; never bypass procedures; path intervention->perception->memory->consideration->decision->action):
- one active record per target/proposition/episode; repeat refreshes, doesn't stack (15-05 §4.5); salience decays in world time over decision cycles, not speed (15-05 §5); no population-tied costs; show stages perceived/considered/acted/told (15-05 §6); distinguish cannot act / not yet / chooses otherwise (From Dust).
- provenance: intervention id saved, chronicle entry, receipts/memories reference it; chronicle says "one recorded influence" (15-05 §6). Previews/inspector consume no draws (06-10 §4.H; 16-03 §1.3). Tests: no hidden command path; anti-spam (15-05 §7).
- Whisper to a notable: adds one authored proposition to their candidates at next deliberation; small attention term decaying over 1-3 decision cycles (15-05 §5 proposed prototype, tuning); only reaches proposal if notable holds the power.
- Bless/curse: shifts target's own keyed chance draws (illness, work quality, spoilage, wear) for a period; never decision weights, trust, votes, detection/punishment (agent's proposal; 15-05 silent).
- Introduce ideology: authored bundle of value-axis positions (+optional preferred constitution); one person hears of it (like IntroduceTechnique aware_only); spreads only by contact; plural interpretation (15-05 §4.4).
- Send agitator: one adult migrant holding the ideology (SpawnFamily precedent), ordinary person, bound by laws.

Dark content (06-10): one structured incident record, kernel renders text; 3 views: event summary / community consequences / individual histories (06-10 §3, §4.C). Plain verbs, actor named, institution & law named; narrator never justifies (Hartmann & Vorderer, 06-10 §2); deny-list ("order restored", "justice was done", "traitor", "rebels crushed"); attribute faction reasons. Responsibility follows control. Actual vs known crime separate (16-01 §1). Show fear-compliance vs agreement, grievance without protest (06-10 §4.B, §4.E; 07-11 §1.7). Attention separate from existence (06-10 §4.F): non-graphic; observer chooses notifications; pause off by default; camera never moves alone; minor thefts as seasonal summaries; killings/punishments/exiles/riots/coups individually. Selector never feeds back. Every death/exile resolves to a record + cause; new Cause values for killing/execution (06-10 §4.H). No sexual violence. Ship a violent incident kind only if engine can answer who did what to whom, under which institution, what changed, what happened after. Tests: causal integrity; presentation independence; perspective consistency (swap faction names); persistence across regime change & save/load; tone lint.

Reference sims (02-06): 1-2k people ≈ 200-400 households ≈ Artificial Anasazi (~250 hh) / VEP (200 hh) scale (02-06 §4). Works: institutions solving specific problems with costs/beneficiaries/opponents (VEP leaders when monitoring costly, 02-06 §1,§5); workload vs capacity (RebeLand queues); explicit relationships not a "stability" number (MASON Hierarchies); office/incumbent/coalition distinct; succession evaluated; every institutional change keeps its record (proposal, supporters, opponents, constraints, obligations) = law history page with 7 stages. Avoid: scripted fragmentation on succession (Gavrilets); curve-fit ≠ explanation (Janssen on Anasazi); one showcase run; complexity ladder/score.
Records (07-09): oral law counts as formal law (Seshat); witnesses/tallies (07-09 §1.1); three layers: what happened / recorded / believed; polity's knowledge of its laws carried by people (like ADR-0008); promulgation = awareness spreading; watch enforces only laws it knows. Capacity as workload: B(t+1)=max(0,B+W-C) in officer-hours (07-09 §1.2); revenue = base×coverage×collection−cost; tribute/tax/levy separate (16-02 §1.6). Clerical figures low-confidence (07-09 §2.2, §6.3).

Validation: crime-poverty row direction only for property offences (16-01 §2.3: 1 pt unemployment ≈ 1-2% property crime, moderate evidence, weak portability; "reference unavailable" over invented band; early-farming crime thinnest 16-01 §6). Measure actual property offences per person-year, poorer half vs richer half, years 26-50 pooled; green if poorer higher in every world with ≥K offences; show recorded beside ungraded. Violence descriptive. No poverty threshold in the crime decision (16-01 §4.3). Regime row: all five worlds same founding institutions & property regime (or classifier ignores property regime); freeze classifier & labels before first run (16-03 §2.2); "differ" only if why names a structural difference. No reference divergence rate. Unrest descriptive; flags: every constitution collapses within years or none ever changes; riots kill without recorded decision. Hard checks: membership/succession valid, one holder per seat, every punishment cites a law in force, fines through ledger. Paired-run tests: no enforcers → no arrests; unheard law changes no compliance; diagnostics toggle leaves run identical; whisper to powerless notable → cannot act. Don't tune toward script: freeze rows, baseline before tuning, hold crime row out, time-box a week, demo from dashboard year-40 saves.
