# Unreal observer

M2 is in progress. The Windows integration runs on Unreal **5.8.3**, MSVC **14.44.35229**
(Visual Studio Build Tools 2022 17.14), Windows SDK **10.0.22621.0**, and the repository's
pinned Rust **1.97.0** MSVC toolchain. Engine binaries are installed at
`D:\Program Files\Epic Games\UE_5.8` on the development PC.

From the repository root:

```powershell
tools\build-unreal.ps1 -Package
tools\run-unreal.ps1          # prefers the packaged executable
tools\run-unreal.ps1 -Editor  # editor in game mode
```

Pass `-Engine <directory>` to use another installation of the pinned engine. The development
PC also has `C:\TCE`, a directory junction to this checkout, to keep compiler and cooking paths
short. It contains the same files, not a second checkout.

The packaged application is `dist\Unreal\Windows\TCE.exe`; it runs without the editor.
Keep the entire `Windows` directory together. The package includes the kernel DLL, content
packs, web panels, and cooked kit. Saves are under the application's `TCE\Saved\Worlds`.
Editor game sessions use `unreal\Saved\Worlds`. Closing normally joins the kernel's threads
and saves a changed world; the two launch modes keep separate save folders.

`tools/test-unreal.ps1` checks the packaged executable end to end. Native Save, Load latest,
clock speed and Quit controls were also exercised on the Windows PC; loading restored the
same 32-person night scene, and Quit removed the session marker normally.

## Controls

The toolbar offers a new valley, pause/resume, clock speeds, following the first resident,
save, loading the latest compatible save, and quit. The embedded web panels offer the
existing inspectors and world/session controls. Click the world before using shortcuts:

| Key | Action |
| --- | --- |
| N | New 512-cell valley, seed 12, 32-person band |
| Space | Pause/resume |
| 1 / 2 / 3 | 1× / 10× / 600× |
| W A S D | Move the camera |
| Mouse wheel | Zoom |
| F | Follow/stop following the first resident |
| Ctrl+S | Save |
| L | Load the latest compatible save |
| Tab | Show/hide the panels |

The shared plugin is in `commons/unreal/EngineBridge`. It negotiates ABI and wire versions,
loads one DLL for the process lifetime, owns copied buffers, drains ordered notifications,
and takes the newest snapshot. Rust alone owns simulation, content, and saves. The observer
reads the existing generated schema; it does not change wire or save formats.

Terrain uses 64-cell runtime procedural-mesh tiles. After an earthwork revision, unchanged
tiles are retained. Citizens use instanced meshes and the shared timed-path interpolation;
paused and Accelerated clocks do not extrapolate. Building stage geometry comes from the
kernel's building query. The small kit is generated by `Tools/build_assets.py`, with Nanite
enabled on timber, walls and roofs. UMG owns the HUD, which contains native Slate controls
and the embedded browser. Panel locate events move the native camera.

## Checks and remaining M2 gates

`-TCESmoke` creates a world, verifies that terrain and citizens arrive, logs `TCE_SMOKE_OK`,
and closes normally. It has passed in editor game mode and in the packaged executable.
`-TCEDemo` creates a valley, advances to the thirteenth night, follows a resident, records
frame timings after warmup, captures `FirstLight.png`, and requests a save.

The kernel interface's ten tests pass, including C/C++ dynamic loading, save-on-destroy,
and authenticated panel hosting. The web builds and its 213 unit tests pass.

This is the first runnable integration, **not completion of the full M2 acceptance gate**.
S1 still needs measured 16 km² performance, edit hitch and PCG/foliage checks. The current kit
and cylinder citizens are deliberately simple; scaffolding, visible hauled goods, lit windows,
water and vegetation presentation, crowd polish, and the final night demo remain to be proved.
There is no terrain collision or LOD selection yet, and worlds larger than the raster query's
one-million-cell limit need tiled requests before this client can display them. No 60 fps
claim is made by the build or smoke checks.
